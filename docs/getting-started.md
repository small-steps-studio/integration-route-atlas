# Getting started

1. Install **Integration Route Atlas** (publisher SmallStepsStudio) from the Extensions view.
2. Open a Camel route file (XML with <route> or YAML with - route: or - from:), or run **Integration Route Atlas: Open Sample File** to open the invented sample.
3. Open the Command Palette (`Ctrl+Shift+P`, on macOS `Cmd+Shift+P`), type `Integration Route Atlas` and pick a report. The button in the editor title bar of *.camel.yaml, *.camel.xml and routes.xml / routes.yaml files runs **Show Route Summary**.
4. The report opens as a new Markdown document (and its preview). Save it, copy it into a ticket, or close it.
5. **Integration Route Atlas: Open Walkthrough** shows the same steps inside the editor.

Every report is described in [reports.md](reports.md). Licence and trial: [licence.md](licence.md). Problems: [troubleshooting.md](troubleshooting.md).
